# Cube3D

Raycasting FPS built collaboratively with an AI agent.

## About

I use this space to experiment with different AI models, harnesses, and development processes — building small games to figure out what works best. Cube3D is my favourite result and the starting point for this collection.

## Tech

- Single-file HTML5 / vanilla JS
- Raycasting renderer with procedural textures
- Z-buffered sprite rendering
- Procedural WebAudio sound effects

## Controls

| Key | Action |
|-----|--------|
| WASD | Move |
| Mouse | Look |
| Click | Shoot |
| R | Reload |
| Shift | Sprint |
