# After playing the game : what was observed 

## distance displayed

Distance seems off, fot it having a sense there should be a sun that would be the starting point for computing distance. Player should spawn near the sun but not into it.
The sun should always be displayed and seeable from afar so that the player has a reference point for orientation.

## Space bases

They look good, but there are too many space bases. It lacks interaction, player should be able to open a menu when interacting with a base to trade for upgrades, simillar to the starting menu, allowing for installing up to 3 different items from the collection logs, or sell them. The collection log becomes an inventory.
